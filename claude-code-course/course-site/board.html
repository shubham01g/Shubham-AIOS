A sign vs a wall

In simple wordsAsking nicely in a prompt is a suggestion. Taking the tool away is a guarantee.
🪧
Prompt layer = a sign

"Please don't send emails"

Works most of the time. "Most of the time" is not good enough with real clients.

suggestion
vs
🧱
Tool layer = a wall

It has no send tool

Our outreach skill writes drafts only. It physically can't send. You send.

guarantee
🔑.envkeys live here, you paste them
🙈.gitignore.env never reaches GitHub
⛔Deny rulesrm -rf · force push · read .env
💳Scoped keysspending limits where you can
Deny beats allow. Even in bypass mode, a deny rule stops it. That's what makes going fast safe.
Rule
Never paste API keys into the chat. "Create a .env placeholder. I'll paste it myself."

Scheduled task / routine

Forever

☁️ The cloud gotcha: a cloud routine runs on a fresh copy of your GitHub repo. Your .env and your local database aren't there. Use a local scheduled task (laptop on), or cloud env vars + a cloud database.
