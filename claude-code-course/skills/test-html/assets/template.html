05  •  Under the hood

What a Skill Actually Is

1

A folder

Lives in ~/.claude/skills/your-skill/

2

A SKILL.md file

Name, description, and the steps, written in plain English.

3

Optional extras

Templates, examples, scripts, loaded only when needed.

~/.claude/skills
$ tree outreach-writer
outreach-writer/
├── SKILL.md         # the recipe
└── examples.md      # good drafts to copy
