• Module 06 • Anatomy •

Open the box, see the recipe

In simple words

A skill is just a folder. One file says what it does, the rest is loaded only when Claude needs it.

~/.claude/skills
$ tree outreach-writer
outreach-writer/
├── SKILL.md          # the recipe
├── references/
│   ├── tone-guide.md   # your voice
│   └── examples.md     # 3 winning emails
└── scripts/
    └── find-hook.py    # pulls 1 fact

$ claude "/outreach-writer Joe's Dental"
✓ Draft ready · 94 words · 1 CTA
🏷️ALWAYS

Front matter

Name + one-line description. This is how Claude knows when to use it.

📜ON USE

SKILL.md body

The step-by-step recipe, your rules, and what "good" looks like.

📚ON DEMAND

references/

Tone guides, examples, price lists. Read only when a step asks.

⚙️ON DEMAND

scripts/

Code that runs the same way every time. No tokens spent explaining it.

Try›Show me every file inside outreach-writer and explain what each one does in one line.
Point out the three loading levels: green is always loaded, amber when the skill runs, violet/pink only when a step needs them.

• Module 06 • Why it matters •

By hand vs by skill

In simple words

Without a skill you repeat yourself every time. With one, your best work becomes the default.

Before · every single time

Prompting from scratch

  • Re-explain your offer and tone
  • Each email sounds a bit different
  • ~15 minutes per decent draft
  • Yesterday's feedback is forgotten
  • Only you can do it
VS
After · one command

/outreach-writer

  • Offer and voice are baked in
  • Same quality on email #1 and #100
  • ~90 seconds per draft
  • Every fix makes the next run better
  • A VA (or Claude) can run it
Try›/outreach-writer for [business name] in [city], they [one fact you found]
Let the room read the left column first. Then say: "This is the moment a skill pays for itself."
