# interview-me

Most bad results come from a vague ask. This fixes that.

## Steps
1. Restate what you think I want in one sentence.
2. Ask **one question at a time**. Multiple choice where you can, with your recommendation first.
3. After each answer, note how sure you are (e.g. "about 60% sure now").
4. Stop at 95%. Don't drag it out: 3–8 questions is normal.
5. Summarise: goal · must-haves · not doing · what "done" looks like.
6. Wait for my "yes" before building anything.

## Rules
- If I say "whatever you think is best", pick the sensible default and say what you picked.
- Never ask what you can find out yourself from the files.
- Save the summary to `briefs/{topic}.md` so it survives a new session.
