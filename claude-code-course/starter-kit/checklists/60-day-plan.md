# 60 days to 2027: first client plan

Tick one box a day. Miss a day? Don't restart, just continue.

## Week 1: finish the capstone
- [ ] Agency site live on a real URL
- [ ] Lead Finder running with 100 scored leads in your niche
- [ ] CLAUDE.md router clean, under 150 lines
- [ ] outreach-writer + proposal-writer skills working
- [ ] Your AIOS answers "what should I do today?"

## Week 2: warm first
- [ ] Trust map: 20 people (clients/trust-map.csv)
- [ ] 5 no-pitch conversations: "where does work feel manual?"
- [ ] Ask each: "do you know anyone this could help?"

## Week 3: get visible
- [ ] Fiverr gig live (3 packages, honest proof only)
- [ ] 10 personalised outreach messages a day, reviewed before sending
- [ ] Track every reply, including the "no"s

## Week 4: pilot
- [ ] Offer a small paid pilot (or free, in exchange for a testimonial) to the warmest lead
- [ ] Scope + definition of done in writing

## Weeks 5–6: deliver
- [ ] Build with the delivery checklist
- [ ] Track results from day 1

## Week 7: proof
- [ ] Results review with the client
- [ ] Testimonial (video if you can)
- [ ] Referral ask
- [ ] Post the case study

## Week 8: recurring
- [ ] Maintenance retainer offered
- [ ] V2 proposal sent
- [ ] Next client in the pipeline

Start 2027 with income, not a plan.
